# labyrinthine-eidolon
# What is this?
This program was created for a school project in which we had to design and create a game or other interactable program in Python using either tkinter or pygame. I chose to make a program that automates the process of running an Eidolon that uses the Labyrinthine layer in the TTRPG Lancer.
# What does that actually mean?
Eidolons are special enemies that have very specific rules and are comprised of layers. Each layer has its own set of rules, and are meant to be played in a certain way. One of these layers is called the Labyrinthine layer, referencing how it is meant to be interacted with. The GM (Game Master) is directed to draw a 3x3 grid and designate two points in secret. Players are then meant to guess where these two points are, suffering penalties for failures but generally being directed towards the correct outcome. If players manage to guess both points correctly at the same time, the layer is destroyed.
# How it works
To start the program, simply run it. On initialization, the program selects a name and tier from a pre-set list and automatically assigns two points on the grid (A/B/C for rows and 1/2/3 for columns). The program itself then waits for the GM to input the players' guesses and checks their inputs against the generated points. If neither match, the program displays a message box telling them as such. If one matches and the other doesn't, a message box appears to tell them this, although it doesn't say which point is correct. All message boxes generated by the program must be closed, either via the exit button in the upper right corner or the confirmation button in the lower right, before any further interaction can be made. There is also a button labelled "TEST", which reflects the action that the Eidolon has access to of the same name. This opens a secondary window leading to a game of rock, paper, scissors. The program automatically chooses one of the three upon the TEST button being pressed, so the corresponding buttons represent the player actions. Upon pressing a button, the corresponding choice is checked against the program's chosen value, and the result is displayed in another message box.
